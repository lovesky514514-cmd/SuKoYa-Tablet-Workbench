# SuKoYa Tablet Workbench

这是你的 Termux 本地代码工作区。

- 左侧：文件 / 文件夹
- 中间：Monaco 编辑器（语法高亮、自动补全、无需 VS Code 扩展）
- 底部：本地运行输出
- 右侧：DeepSeek AI 对话，可附带当前文件作为上下文
- 快捷键：Ctrl+S 保存，Ctrl+Enter 运行

默认工作目录：`~/workbench-projects`

支持直接运行：Python / JavaScript / TypeScript / C / C++ / Rust / Go / Java / Shell。
HTML 使用“预览”按钮。
